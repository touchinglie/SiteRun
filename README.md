# SiteRun

SiteRun 是一个 Typecho 插件，用于在网站页脚显示后台管理入口和网站运行时间。

## 功能

- 在首页页脚显示「后台管理」链接
- 在首页页脚显示「网站已运行：x年x天x小时x分」的运行时长统计

实际输出样式与 Typecho 官方新版主题 Classic 22 适配。

## 安装

1. 将插件的 `SiteRun` 目录上传到 Typecho 的 `/usr/plugins/` 目录下。
2. 进入后台「控制台 -> 插件管理」，启用 `SiteRun`。
3. 前往「控制台 -> 设置插件 -> SiteRun」配置开始时间。

## 配置

- 博客开始时间：填写网站开始运行的时间，格式如 `2020-01-01 00:00:00`。插件会按照后台设置的时区解析该时间，避免服务器时区不一致导致的偏差。

## 说明

- 若未填写，插件会默认开始时间为2020-01-01 00:00:00。
- 运行时长按一年 365.2425 天（约 31556926 秒）计算。
